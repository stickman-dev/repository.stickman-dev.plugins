# Stickman-Dev Kodi Add-ons

Add this repository to Kodi to download the Kodi add-ons and keep them up to date.

## Installing

Either:
- Download the zip from [Releases](https://github.com/stickman-dev/repository.stickman-dev.plugins/releases/latest) and install it from zip file, or
- In Kodi, add a file source pointing at `https://stickman-dev.github.io/repository.stickman-dev.plugins/` and install from zip file from there.
